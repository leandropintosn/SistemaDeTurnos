Sistema de Reserva de Turnos para Club de Fútbol
Descripción del Proyecto
Este proyecto es un sistema de reserva de turnos para un club de fútbol que cuenta con dos canchas. Fue desarrollado en lenguaje C como parte de un proyecto universitario. Permite a los usuarios realizar las siguientes operaciones a través de una interfaz de consola:

Reservar turnos en cualquiera de las dos canchas.
Cancelar reservas existentes.
Reagendar turnos previamente reservados.
Consultar la disponibilidad horaria de cada cancha.
El sistema está diseñado para ser simple y funcional, ideal para la gestión básica de horarios en un entorno de club deportivo.

Características
Gestión de 2 Canchas: Soporte para dos canchas de fútbol con horarios individuales.
Reserva de Turnos: Permite a los usuarios elegir una cancha, fecha y hora para su reserva.
Cancelación de Turnos: Facilita la eliminación de reservas existentes.
Reagendamiento: Ofrece la opción de modificar la fecha o la hora de una reserva.
Consulta de Disponibilidad: Muestra los horarios ocupados y disponibles para cada cancha en un día específico.
Interfaz de Consola: Interacción completa a través de la terminal, lo que lo hace ligero y eficiente.
Tecnologías Utilizadas
Lenguaje de Programación: C
Entorno de Desarrollo: Compatible con compiladores C estándar (GCC, Clang, etc.).
